Modo de uso:
Passo 1: Digitar o tipo de desastre a ser reportado<br>
Passo 2: Preencher os campos detalhando o desastre<br>
Passo 3: Inserir a quantidade de pessoas afetadas no total<br>
Passo 4: Inserir quantidade de pessoas afetadas por categoria (Crianças, adultos, idosos, pessoa com mobilidade reduzida e pessoas feridas)<br>
Passo 5: Caso queira adionar mais uma ocorrência digitem Sim, senão, digite Não<br>
Passo 6: Se tiver escolhido por adicionar mais uma ocorrência, realize o passo a passo tudo denovo, se tiver recusado irá aparecer a análise do registro<br>
